Privacy Policy

Kontenbot is a private tool used only by its owner to create short videos and publish them to the owner's own YouTube channels and Facebook Pages. It is not offered to the public.

Data accessed. With the owner's permission (Google OAuth), Kontenbot uses the YouTube Data API and YouTube Analytics API to: upload videos to the owner's channel, read the owner's channel name and statistics, and read analytics reports (views, watch time, likes, comments, subscribers) for the owner's own channel.

Storage. OAuth tokens and reports are stored only on the owner's personal computer. No data is sold, shared with third parties, or used for advertising.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions. Deleting the stored token file removes all saved credentials.

Kontenbot uses YouTube API Services. By using it you also agree to the YouTube Terms of Service and the Google Privacy Policy.
